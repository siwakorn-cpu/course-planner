# ระบบจัดรายวิชานักเรียน (Course Planner)

เว็บแอปช่วยครูฝ่ายบริหารวิชาการ **ติดตามหน่วยกิตของนักเรียน** และ **วางแผนการจัดสอน / อัตรากำลังครู**
รองรับทั้ง ม.ต้น (ม.1–3) และ ม.ปลาย (ม.4–6) · หน้าจอภาษาไทยทั้งหมด · ใช้ฟอนต์ Sarabun

> ข้อมูลถูกเก็บไว้ใน **เบราว์เซอร์ของเครื่องคุณเอง** (localStorage) ไม่ต้องมีเซิร์ฟเวอร์
> และมีปุ่ม **สำรอง/นำเข้าเป็นไฟล์ JSON** เพื่อย้ายเครื่องหรือเก็บสำรองได้

## สิ่งที่ต้องมีก่อน (ติดตั้งครั้งเดียว)

- **Node.js** เวอร์ชัน 18 ขึ้นไป (แนะนำ 20+) — ดาวน์โหลดจาก <https://nodejs.org>
  ตรวจสอบว่าติดตั้งแล้วโดยพิมพ์ในโปรแกรม Terminal:
  ```bash
  node -v
  ```
  ถ้าขึ้นเลขเวอร์ชัน (เช่น `v20.11.0`) แปลว่าพร้อมใช้งาน

## ขั้นตอนการใช้งาน (ทีละขั้น)

### 1) เปิด Terminal มาที่โฟลเดอร์โปรเจกต์
```bash
cd "course-planner"
```

### 2) ติดตั้งไลบรารี (ทำครั้งแรกครั้งเดียว)
```bash
npm install
```

### 3) รันเพื่อใช้งาน (โหมดพัฒนา)
```bash
npm run dev
```
จากนั้นเปิดเว็บเบราว์เซอร์ไปที่ลิงก์ที่ขึ้นมา (ปกติคือ **http://localhost:5173**)
เมื่อเปิดครั้งแรกจะมี **ข้อมูลตัวอย่าง** ให้ดูทันที

หยุดการทำงานด้วยการกด `Ctrl + C` ใน Terminal

### 4) สร้างไฟล์สำหรับนำไปใช้จริง (build)
```bash
npm run build
```
ผลลัพธ์จะอยู่ในโฟลเดอร์ `dist/` — นำไปวางบนเว็บโฮสต์ใดก็ได้ หรือดูตัวอย่างไฟล์ที่ build แล้วด้วย:
```bash
npm run preview
```

### 5) ทดสอบความถูกต้องของการคำนวณ
```bash
npm run test
```

| **ครูผู้สอน** | เพิ่ม/แก้/ลบ/**นำเข้า Excel** รายชื่อครู + ดูคาบสอนรวมและ %เทียบภาระงานของแต่ละคน |

| **หน่วยกิตรวมสะสม** | หน่วยกิตสะสม = **เดิม + ปีนี้** เทียบเกณฑ์จบ + **ทำเนียบจบการศึกษา** + Export CSV |
| **ภาระงาน & อัตรากำลัง** | คาบสอนรวมต่อกลุ่มสาระ + ครูที่ต้องใช้ + **คลิกกลุ่มสาระเพื่อกางดูภาระงานรายครู** + Export CSV |
| **ตั้งค่า** | ค่าการคำนวณ, เกณฑ์หน่วยกิต, **จัดการแผนการเรียน/กลุ่มการเรียน**, สำรอง/นำเข้าข้อมูล, ล้างเริ่มใหม่ |

## นำเข้ารายวิชาจาก Excel

ในแท็บ **คลังรายวิชา** มีปุ่ม 2 ปุ่ม:

1. **⬇️ แม่แบบ Excel** — ดาวน์โหลดไฟล์ `แม่แบบนำเข้ารายวิชา.xlsx` ที่มีหัวคอลัมน์ถูกต้องและตัวอย่าง
   (มีชีต “คำอธิบาย” บอกค่าที่ใช้ได้ของแต่ละช่อง)
2. **⬆️ นำเข้า Excel** — เลือกไฟล์ `.xlsx` / `.xls` / `.csv` ที่กรอกไว้ ระบบจะ **ตรวจสอบทุกแถวก่อน**
   แล้วแสดงสรุปว่า *เพิ่มใหม่ / อัปเดตทับ / ผิดพลาด (พร้อมเหตุผล)* → กดยืนยันจึงบันทึกจริง

**คอลัมน์ที่ต้องมี:** รหัสวิชา · ชื่อวิชา · กลุ่มสาระ · ประเภท · หน่วยกิต · ระดับ
(คอลัมน์ **คาบ/สัปดาห์** เว้นว่างได้ ระบบจะคำนวณจากหน่วยกิตให้อัตโนมัติ)

ระบบยืดหยุ่นกับข้อมูล เช่น พิมพ์ “วิทยาศาสตร์” แทน “วิทยาศาสตร์และเทคโนโลยี”, “ปลาย” แทน “ม.ปลาย”,
“เพิ่ม” แทน “เพิ่มเติม” ก็เข้าใจได้ · **ถ้ารหัสวิชาซ้ำกับที่มีอยู่ = อัปเดตทับของเดิม**
(คง id ไว้ การจัดสอนที่อ้างวิชานั้นจึงไม่หลุด)

> **นำเข้าครูจาก Excel** ก็ทำได้เช่นกัน — ที่แท็บ “ครูผู้สอน” มีปุ่มแม่แบบ/นำเข้า
> คอลัมน์: **ชื่อ-สกุล** (จำเป็น) และ **กลุ่มสาระ** (เว้นว่างได้) · ชื่อซ้ำ = อัปเดตของเดิม

## เลื่อนชั้น / ขึ้นปีการศึกษา

ที่แท็บ “ห้องเรียน” มีปุ่ม **🎓 เลื่อนชั้น** เลื่อนทุกห้องขึ้น 1 ระดับในคลิกเดียว (มีกล่องยืนยัน + แนะนำ Export ก่อน):

- **ม.1→ม.2, ม.2→ม.3, ม.4→ม.5, ม.5→ม.6** โดย**รุ่นคงเดิม**
- **วิชาที่จัดปีนี้** (offerings) จะถูก**โอนเข้า “หน่วยกิตเดิม”** ของห้อง แล้ว**ล้าง**ให้พร้อมจัดปีใหม่ (หน่วยกิตสะสมจึงต่อเนื่อง)
- **ม.3 และ ม.6 = จบการศึกษา** → ย้ายเข้า **“ทำเนียบจบการศึกษา”** (ดูได้ที่แท็บ “หน่วยกิตรวมสะสม” ด้านล่าง ไม่หาย)

> เป็นการเปลี่ยนข้อมูลถาวร ควร Export สำรอง (แท็บตั้งค่า) ก่อนทุกครั้ง

## หน่วยกิตเดิม (วิชาที่เรียนจบไปแล้ว)

บันทึกวิชาที่ห้อง/รุ่นนั้นเรียนจบไปแล้ว (เช่น ปีก่อน ๆ) เพื่อดูหน่วยกิตสะสมเดิม

**วิธีใช้ (กรอกทีละวิชา):** แท็บ “ห้องเรียน” → การ์ดห้อง → ปุ่ม **📚 หน่วยกิตเดิม** → เพิ่มวิชา (รหัส/ชื่อ/หน่วยกิต/ประเภท/หมายเหตุปี-ภาคเรียน)

**วิธีนำเข้าทีละหลายรายการ (Excel):** แท็บ “หน่วยกิตรวมสะสม” → ปุ่ม **⬇️ แม่แบบหน่วยกิตเดิม / ⬆️ นำเข้าหน่วยกิตเดิม**
- ไฟล์ระบุ **ระดับชั้น/ห้อง/รุ่น** เพื่อจับคู่กับห้องที่มีในระบบ (ต้องสร้างห้องไว้ก่อน) + รหัส/ชื่อ/หน่วยกิต/ประเภท/กลุ่มเลือก/หมายเหตุ
- รหัสวิชาซ้ำในห้องเดิม = อัปเดต · ตรวจทุกแถวก่อนยืนยัน

- เก็บ**ระดับห้อง/รุ่น** (ตามโครงของแอป) แยกจาก “การจัดสอนปัจจุบัน”
- แสดงเป็น**บล็อกแยก**ในหน้า “สรุปหน่วยกิต” (“เรียนไปแล้ว (สะสมเดิม)”) — ไม่นำไปบวกรวมกับยอดที่กำลังจัดโดยอัตโนมัติ
- รวมอยู่ในไฟล์ Export/Import JSON ด้วย

## กลุ่มเลือกภายในห้อง (วิชาเลือกที่ต่างกันในห้องเดียว)

รองรับกรณีนักเรียนในห้องเดียวกันเลือกวิชาเพิ่มเติมต่างกลุ่มกัน (เช่น ในห้อง ม.4/5 มีทั้งกลุ่มภาษาจีนและภาษาญี่ปุ่น)

**วิธีใช้:** ที่แท็บ “จัดรายวิชา” เวลาเพิ่มวิชา ให้กรอกช่อง **กลุ่มเลือก**
- เว้นว่าง = วิชาที่ **ทั้งห้องเรียนร่วมกัน** (วิชาพื้นฐาน ฯลฯ)
- ใส่ชื่อกลุ่ม เช่น `ภาษาจีน` = วิชาที่ **เฉพาะกลุ่มนั้น** เรียน

**ผลต่อการคำนวณ:**
- **หน่วยกิต** — หน้า “สรุปหน่วยกิต” จะแยกเทียบเกณฑ์จบ **รายกลุ่ม** (หน่วยกิตของนักเรียน = วิชาร่วมทั้งห้อง + วิชาของกลุ่มที่เขาเลือก) จึงไม่นับซ้ำเกินจริง
- **คาบสอน/อัตรากำลังครู** — แต่ละกลุ่มนับเป็นคาบสอนจริงแยกกัน (เพราะครูต้องสอนทุกกลุ่ม) จึงสะท้อนภาระงานจริง

### ห้องรวม (เรียนพื้นฐานร่วมกัน แยกวิชาเพิ่มเติม) เช่น ม.5/5,6,7

กรณีหลายห้องเรียน**พื้นฐานร่วมกัน** (ครูสอนทีเดียว = 1 ชุดคาบ) แต่**วิชาเพิ่มเติมแยกกัน**:
1. สร้างเป็น **ห้องเดียว** ระดับ ม.5 ห้อง **“5,6,7”**
2. วิชาพื้นฐาน (เรียนร่วม) → เว้นกลุ่มเลือกว่าง → นับ **1 ชุดคาบ** (ไม่คูณ 3)
3. วิชาเพิ่มเติม → ใส่กลุ่มเลือกตามห้องย่อย — ระบบ **เติมกลุ่มย่อยให้อัตโนมัติ** จากชื่อห้อง (5,6,7 → เลือก `5/5`, `5/6`, `5/7` ได้เลย)

**ตรวจสอบรายห้องย่อย:** ที่แท็บ “หน่วยกิตรวมสะสม” แต่ละกลุ่มย่อยมีปุ่ม **“ดูรายวิชาของกลุ่มนี้”** → เห็นรายวิชา (เดิม + ปีนี้) และหน่วยกิตสะสมของ 5/5, 5/6, 5/7 **แยกกัน**

## กฎการคำนวณ (ปรับได้ในแท็บ “ตั้งค่า”)

- **แปลงหน่วยกิต ↔ คาบ:** 1 หน่วยกิต = 2 คาบ/สัปดาห์ (ค่าเริ่มต้น)
- **หน่วยกิตของห้อง** = ผลรวมหน่วยกิตของทุกวิชาที่จัดให้ห้องนั้น (แยกพื้นฐาน/เพิ่มเติม/รวม, รวมทุกภาคเรียน)
- **ภาระคาบของกลุ่มสาระ** = ผลรวมคาบของการจัดสอนทั้งหมดในกลุ่มสาระนั้น (ดูรายภาคเรียน/ทั้งปีได้)
- **ครูที่ต้องใช้** ≈ คาบรวมของกลุ่มสาระ ÷ ภาระงานมาตรฐาน (ค่าเริ่มต้น 20 คาบ/คน) แล้วปัดขึ้น

### เกณฑ์หน่วยกิตการจบ (ค่าตั้งต้นตามหลักสูตรแกนกลางฯ 2551)
- **ม.ต้น:** พื้นฐาน 63 นก., รวมไม่เกิน 81 นก., กิจกรรมพัฒนาผู้เรียน 360 ชม.
- **ม.ปลาย:** พื้นฐาน 41 นก., เพิ่มเติม ≥ 40 นก., รวม ≥ 81 นก., กิจกรรมพัฒนาผู้เรียน 360 ชม.

> ทุกค่าข้างต้นแก้ไขได้ในแท็บ “ตั้งค่า” (ใส่ 0 = ไม่ใช้เกณฑ์นั้น)

## คำถามที่พบบ่อย

**ข้อมูลหายไหมถ้าปิดเบราว์เซอร์?**
ไม่หาย — เก็บอยู่ในเครื่อง แต่ถ้า “ล้างข้อมูลเบราว์เซอร์” หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
จึงควรกด **Export** ในแท็บตั้งค่าเพื่อสำรองไฟล์ไว้เป็นระยะ

**อยากเริ่มจากข้อมูลว่าง ๆ?**
ลบข้อมูลตัวอย่างทีละรายการ หรือใช้ปุ่ม “ล้างข้อมูลทั้งหมด” (จะโหลดตัวอย่างกลับมา) แล้วค่อยลบ/แก้ตามต้องการ
